Esta é a documentação da API da [Olie](https://olie.ai/). Aqui você encontra como autenticar as requisições, como ler as respostas e a referência de cada endpoint, para integrar a Olie com outros sistemas.

## Como a API funciona

A API oferece as mesmas funções que as interfaces da Olie usam. Todas as requisições usam HTTPS e o domínio [api.olie.ai](https://api.olie.ai).

Parte dos recursos segue o padrão REST, como `GET /api/management/projects` para listar projetos. Outros usam um endpoint `POST` com o nome da ação no caminho, como `POST /api/management/get-form`. A referência de cada endpoint mostra o método e o caminho exatos.

## Testar com o Postman

Você pode explorar e testar a API no [Postman](https://www.postman.com/). A [coleção oficial da Olie no Postman](https://www.postman.com/olieai/workspace/olie-s-public-workspace/collection/49535030-f6786f52-3575-41f2-967a-9b4b71270ee8?active-environment=49535030-67d0fe41-9d71-4d0f-9629-297b50a55f03) traz os endpoints documentados aqui e é atualizada com frequência. Use a coleção para fazer requisições reais e ver a estrutura de cada endpoint.
