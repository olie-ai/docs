Esta página é para **parceiros** do Marketplace. Ela explica o que acontece depois que você submete um template: os status da revisão do time Olie, o que fazer em cada um e como resubmeter.

## Submetendo um template

Depois de [criar o template](/guides/marketplace/creating-template), preencher os campos e selecionar o snapshot, submeta o template para a revisão do time Olie. A submissão inicia o processo de moderação.

## Status do template

Cada submissão é revisada pelo time Olie, e o resultado da revisão muda o status do template. Depois da submissão, o template passa pelos status abaixo.

| Status | O que significa | O que você faz |
| --- | --- | --- |
| **Em análise** | O template foi submetido e aguarda a revisão do time Olie. | Nada. Aguarde a revisão. |
| **Aprovado** | O template foi aprovado e publicado no Marketplace. Usuários já podem ver e adquirir o template. | Acompanhe o template no [painel do parceiro](/guides/marketplace/managing-templates). |
| **Alterações solicitadas** | O moderador revisou o template e pediu ajustes. | Siga o [ciclo de resubmissão](#ciclo-de-resubmissão). |
| **Rejeitado ou despublicado** | O time Olie rejeitou a submissão, e o template ficou despublicado. | Não é possível resubmeter. Veja o aviso abaixo. |

<Warning>
A rejeição de uma submissão é definitiva: o template fica despublicado e você não pode resubmetê-lo. Se ainda quiser publicar o conteúdo no Marketplace, crie um novo template e submeta-o para revisão.
</Warning>

## Notificações

Você recebe um e-mail sempre que o status do template muda: aprovação, solicitação de alterações ou rejeição.

## Ciclo de resubmissão

Quando o status do template muda para **Alterações solicitadas**, corrija o template e resubmeta seguindo os passos abaixo.

<Steps>
<Step title="Leia o feedback">
  Leia, no painel do parceiro, o feedback do moderador com as alterações solicitadas.
</Step>

<Step title="Edite a empresa construtora">
  Faça os ajustes na [empresa construtora](/guides/marketplace/template-builder).
</Step>

<Step title="Gere um novo snapshot">
  [Gere um novo snapshot](/guides/marketplace/snapshots) para capturar o estado atualizado do ambiente.
</Step>

<Step title="Atualize o template">
  Edite o template, selecione o novo snapshot e escreva uma justificativa explicando as alterações feitas.

  Se precisar, aproveite para editar também nome, descrições, categorias e imagens.
</Step>

<Step title="Resubmeta para análise">
  Envie o template novamente para revisão. O status volta para **Em análise**.
</Step>
</Steps>

O ciclo se repete até o template ser aprovado ou rejeitado.

<Tip>
Na justificativa, explique como você tratou cada ponto do feedback. Isso agiliza a revisão.
</Tip>

## Histórico de submissões

O painel do parceiro guarda o histórico completo das submissões, com os feedbacks dos moderadores e as justificativas de resubmissão. Use o histórico para acompanhar a evolução do template.
