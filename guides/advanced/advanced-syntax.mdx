A **sintaxe avançada** é a linguagem de template que a Olie aceita nos campos que recebem expressão. Esses campos incluem as mensagens e os campos das automações, o corpo customizado de webhook e o prompt dos assistentes de etapa. Com ela, um texto fixo passa a usar os dados do projeto: você insere variáveis, mostra um trecho conforme uma condição, percorre listas e busca dados com a função `query`.

Esta página é a referência da linguagem. Para saber quais dados cada automação recebe, veja [Variáveis nas automações](/guides/automation/variables).

## Variáveis dinâmicas

Uma variável insere no texto um dado do contexto, como o nome do projeto ou do cliente.

### Sintaxe básica

```twig
{{ variavel }}
```

<Tabs>
<Tab title="Variáveis simples">
  ```twig
  Olá, {{ user.name }}!
  Seu e-mail é {{ user.email }}.
  ```
  
  **Resultado:**
  ```text
  Olá, João Silva!
  Seu e-mail é joao@exemplo.com.
  ```
</Tab>

<Tab title="Variáveis aninhadas">
  ```twig
  Projeto: {{ project.code }} - {{ project.name }}
  Cliente: {{ project.customer.name }}
  Status: {{ project.status }}
  ```
  
  **Resultado:**
  ```text
  Projeto: P-1 - Website Institucional
  Cliente: Oficina Norte
  Status: 1
  ```
</Tab>

<Tab title="Arrays e listas">
  ```twig
  {% set lista = ['A', 'B', 'C'] %}
  Primeiro item: {{ lista[0] }}
  Último item: {{ lista[-1] }}
  Total de itens: {{ lista|length }}
  ```
  
  **Resultado:**
  ```text
  Primeiro item: A
  Último item: C
  Total de itens: 3
  ```
</Tab>
</Tabs>

### Verificação de existência

Nem toda variável existe em todo contexto. A variável `user`, por exemplo, só existe quando uma pessoa disparou a automação. Para evitar erro, verifique a variável com `is defined` antes de usá-la:

```twig
{% if user is defined %}
  Movido por {{ user.name }}.
{% else %}
  Disparo sem pessoa associada.
{% endif %}
```

## Condicionais

Uma condicional mostra um trecho ou outro conforme o valor de um dado.

### Estrutura if/else

<Tabs>
<Tab title="If simples">
  ```twig
  {% if project.budget >= 100000 %}
    Projeto com orçamento a partir de R$ 100 mil.
  {% endif %}
  ```
</Tab>

<Tab title="If/Else">
  ```twig
  {% if project.impact < 3 %}
    ⚠️ URGENTE: Este projeto requer atenção imediata!
  {% else %}
    📋 Projeto regular
  {% endif %}
  ```
</Tab>

<Tab title="If/Elseif/Else">
  ```twig
  {% if project.impact < 3 %}
    ✅ Projeto de alto impacto
  {% elseif project.impact < 6 %}
    🚀 Projeto de médio impacto
  {% else %}
    📋 Projeto de baixo impacto
  {% endif %}
  ```
</Tab>

</Tabs>

### Operadores de comparação

Os operadores abaixo servem dentro de `if` e `elseif`:

<AccordionGroup>
<Accordion title="Igualdade e diferença" icon="equals">
  ```twig
  {% if valor == 10 %}      {# Igual a #}
  {% if valor != 10 %}      {# Diferente de #}
  ```
</Accordion>

<Accordion title="Comparações numéricas" icon="greater-than">
  ```twig
  {% if valor > 18 %}       {# Maior que #}
  {% if valor >= 18 %}      {# Maior ou igual #}
  {% if valor < 18 %}       {# Menor que #}
  {% if valor <= 18 %}      {# Menor ou igual #}
  ```
</Accordion>

<Accordion title="Operadores lógicos" icon="code-merge">
  ```twig
  {% if a and b %}          {# E lógico #}
  {% if a or b %}           {# OU lógico #}
  {% if not a %}            {# NÃO lógico #}
  ```
</Accordion>

<Accordion title="Testes especiais" icon="vial">
  ```twig
  {% if variavel is defined %}     {# Está definida #}
  {% if variavel is null %}        {# É nula #}
  {% if variavel is empty %}       {# É vazia #}
  {% if numero is even %}          {# É par #}
  {% if numero is odd %}           {# É ímpar #}
  ```
</Accordion>
</AccordionGroup>

## Loops (for)

Um laço (`for`) percorre uma lista e repete um trecho para cada item.

### Estrutura básica

```twig
{% for item in lista %}
  {{ item }}
{% endfor %}
```

<Tabs>
<Tab title="Lista simples">
  As etiquetas não vêm no contexto, então o exemplo as busca com [`query`](#funções-de-consulta) antes do laço:

  ```twig
  Etiquetas do projeto:
  {% set p = query('project_details', { 'project_code': project.code }) %}
  {% for tag in p.tags %}
  - {{ tag.name }}
  {% endfor %}
  ```
  
  **Resultado:**
  ```text
  Etiquetas do projeto:
  - Aguardando retorno
  - Prioridade alta
  ```
</Tab>

<Tab title="Com índice">
  ```twig
  {% for item in lista %}
    {{ loop.index }}. {{ item }}
  {% endfor %}
  ```
  
  **Variáveis especiais do loop:**
  - `loop.index` - Índice atual (começa em 1)
  - `loop.index0` - Índice atual (começa em 0)
  - `loop.first` - `true` na primeira iteração
  - `loop.last` - `true` na última iteração
  - `loop.length` - Total de itens
</Tab>

<Tab title="Com condicionais">
  ```twig
  {% set p = query('project_details', { 'project_code': project.code }) %}
  {% for tag in p.tags %}
    {% if tag.name == 'Aguardando retorno' %}
      ⏳ Projeto aguardando retorno do cliente
    {% endif %}
  {% endfor %}
  ```
</Tab>

<Tab title="Loop vazio">
  ```twig
  {% for item in lista %}
    - {{ item }}
  {% else %}
    Nenhum item encontrado.
  {% endfor %}
  ```
  
  O bloco `else` roda quando a lista está vazia.
</Tab>
</Tabs>

### Loops com ranges

Um range, como `1..5`, gera uma sequência numérica para o laço percorrer:

```twig
{% for i in 1..5 %}
  Número {{ i }}
{% endfor %}
```

**Resultado:**
```text
Número 1
Número 2
Número 3
Número 4
Número 5
```

## Filtros

Um filtro transforma um valor antes de exibi-lo. Ele vem depois de uma barra vertical (`|`), e vários filtros podem ser encadeados.

### Sintaxe de filtros

```twig
{{ variavel|filtro }}
{{ variavel|filtro(parametro) }}
{{ variavel|filtro1|filtro2 }}
```

<Tabs>
<Tab title="Texto">
  ```twig
  {{ nome|upper }}              {# JOÃO SILVA #}
  {{ nome|lower }}              {# joão silva #}
  {{ nome|capitalize }}         {# João silva #}
  {{ nome|title }}              {# João Silva #}
  {{ texto|trim }}              {# Remove espaços #}
  {{ texto|length }}            {# Conta caracteres #}
  {{ texto|json }}              {# Converte para JSON #}
  {{ texto|json(true) }}        {# Converte para JSON com indentação #}
  ```
</Tab>

<Tab title="Números">
  ```twig
  {{ preco|number_format(2, ',', '.') }}
  {# 1.234,56 #}
  
  {{ valor|round }}             {# Arredonda #}
  {{ valor|round(2) }}          {# 2 decimais #}
  {{ valor|abs }}               {# Valor absoluto #}
  ```
</Tab>

<Tab title="Datas">
  ```twig
  {{ data|date("d/m/Y") }}      {# 21/01/2026 #}
  {{ data|date("d/m/Y H:i") }}  {# 21/01/2026 14:30 #}
  {{ data|date("F Y") }}        {# Janeiro 2026 #}
  {{ project.created_at|date_modify("+15 days")|date("Y-m-d") }}  {# Soma 15 dias #}
  ```
</Tab>

<Tab title="Arrays">
  ```twig
  {{ lista|length }}            {# Tamanho #}
  {{ lista|first }}             {# Primeiro item #}
  {{ lista|last }}              {# Último item #}
  {{ lista|join(', ') }}        {# Une com vírgula #}
  {{ lista|reverse }}           {# Inverte ordem #}
  {{ lista|sort }}              {# Ordena #}
  {{ lista|unique }}            {# Remove duplicatas #}
  {{ lista|json }}              {# Converte para JSON #}
  {{ lista|json(true) }}        {# Converte para JSON com indentação #}
  ```
</Tab>

<Tab title="Objetos">
  ```twig
  {{ objeto|json }}              {# Converte para JSON #}
  {{ objeto|json(true) }}        {# Converte para JSON com indentação #}
  ```
</Tab>
</Tabs>

### Outros filtros úteis

Estes filtros completam a lista:

<AccordionGroup>
<Accordion title="mention" icon="at">
  Transforma um usuário, ou uma lista de usuários, em menção.
  
  ```twig
  {{ user|mention }}
  {{ project.users|mention }}
  ```
  
  [Saiba mais sobre menções →](/guides/automation/mention-users)
</Accordion>

<Accordion title="default" icon="shield-halved">
  Define um valor padrão se a variável for vazia.
  
  ```twig
  {{ nome|default('Nome não informado') }}
  ```
</Accordion>

<Accordion title="escape" icon="shield">
  Escapa caracteres especiais para segurança.
  
  ```twig
  {{ texto|escape }}
  {{ texto|e }}  {# Atalho #}
  ```
</Accordion>

<Accordion title="json" icon="code">
  Converte para JSON. Serve para inspecionar um dado no registro de execução e para [devolver uma lista](/guides/automation/variables#devolvendo-listas-em-vez-de-texto) em campos que esperam lista.
  
  ```twig
  {{ lista|json }}              {# Converte para JSON #}
  {{ lista|json(true) }}        {# Converte para JSON com indentação #}
  ```
</Accordion>
</AccordionGroup>
 
## Funções de consulta

Nem tudo que você precisa está disponível no contexto. A função `query` busca o que falta, direto da plataforma, no meio da expressão.

### Sintaxe

```twig
query('nome_da_consulta', { 'parametro': valor })
```

O retorno é uma estrutura de dados, não um texto — por isso `query` quase sempre vem com `set`:

```twig
{% set p = query('project_details', { 'project_code': project.code }) %}
{{ p.name }}
```

### Consultas disponíveis

A tabela lista as consultas, os parâmetros de cada uma e o que elas devolvem:

| Consulta | Parâmetros | Devolve |
| --- | --- | --- |
| `project_details` | `project_code` **ou** `id` | O projeto completo, com etiquetas, funis, etapas e respostas |
| `project_dynamic_forms` | `project_code` | Os formulários dinâmicos do projeto; cada item traz `pivot` e `form_answers` |
| `project_medias` | `project_code` | `medias` (o conteúdo publicado no projeto) e `pagination` |
| `get_form_answers` | [`pivot`](/api-reference/general/form-answer-pivot) — opcionais: `edge_id`, `format` | As respostas de um formulário, dentro de `response` |
| `user_details` | `user_id` | Os dados de um usuário |
| `user_email` | `user_id` | O e-mail principal do usuário, como texto |

### Exemplos

<Tabs>
<Tab title="Etiquetas do projeto">
  Etiquetas não vêm carregadas no contexto — é preciso buscá-las:

  ```twig
  {% set p = query('project_details', { 'project_code': project.code }) %}
  {% for tag in p.tags %}{{ tag.name }}{% if not loop.last %}, {% endif %}{% endfor %}
  ```
</Tab>

<Tab title="Respostas de um formulário">
  `get_form_answers` precisa do `pivot` — o endereço que diz **onde** o formulário está anexado. Ele vem pronto de `project_dynamic_forms`, e as duas consultas se encadeiam:

  ```twig
  {% set formularios = query('project_dynamic_forms', { 'project_code': project.code }) %}
  {% for f in formularios %}
    {% set respostas = query('get_form_answers', { 'pivot': f.pivot }) %}
    {{ respostas.response|json(true) }}
  {% endfor %}
  ```
</Tab>

<Tab title="E-mail de um responsável">
  ```twig
  {% for u in project.users %}{{ query('user_email', { 'user_id': u.id }) }}
  {% endfor %}
  ```
</Tab>

<Tab title="Descobrir o formato">
  Na dúvida sobre o que a consulta devolve, imprima tudo uma vez e olhe o resultado no registro de execução:

  ```twig
  {{ query('project_medias', { 'project_code': project.code })|json(true) }}
  ```
</Tab>
</Tabs>

### Cuidados

<AccordionGroup>
<Accordion title="Limite de consultas" icon="gauge-high">
  Cada expressão pode executar no máximo **50 consultas**. Um `query` dentro de um laço conta uma vez por iteração — cuidado ao consultar dentro de `for`.
</Accordion>

<Accordion title="Quando a consulta não encontra nada" icon="circle-question">
  O retorno é nulo. Proteja antes de usar:

  ```twig
  {% set p = query('project_details', { 'project_code': project.code }) %}
  {% if p %}{{ p.name }}{% else %}Projeto não encontrado{% endif %}
  ```
</Accordion>

<Accordion title="Nome ou parâmetro errado" icon="triangle-exclamation">
  Um nome de consulta que não existe, ou a falta de um parâmetro obrigatório, interrompe a expressão e registra `template_error`. O [registro de execução](/guides/automation/logs) mostra a mensagem. Corrija o nome ou o parâmetro conforme a tabela de [consultas disponíveis](#consultas-disponíveis).
</Accordion>

<Accordion title="Escopo e repetição" icon="shield-halved">
  As consultas são resolvidas sempre dentro da sua própria conta — não há como acessar dados de outra. E a mesma consulta, com os mesmos parâmetros, é reaproveitada em vez de repetida.
</Accordion>
</AccordionGroup>

## Como funciona o mecanismo

A sintaxe avançada é baseada no **Twig**, uma linguagem de templates. A Olie roda as expressões em um ambiente controlado: só um conjunto conhecido de blocos, filtros e funções é permitido, e há limites de laço, consultas e tempo. Os valores estão em [Limites do mecanismo](/guides/automation/variables#limites-do-mecanismo).

A documentação oficial do Twig explica a linguagem em detalhe. Um recurso do Twig que não aparece nesta página pode não estar liberado na Olie.
