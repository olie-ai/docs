## Visão geral

É possível utilizar **sintaxe avançada** para deixar os blocos de texto, automações e templates ainda mais inteligentes e adaptáveis ao contexto. Essa funcionalidade permite incorporar lógica condicional, iteração de listas, e até chamadas de funções de consulta.

<Info>
A sintaxe avançada transforma conteúdos estáticos em templates dinâmicos que se adaptam automaticamente aos dados disponíveis.
</Info>

## Conceitos-chave

<CardGroup cols={2}>
<Card title="Variáveis dinâmicas" icon="brackets-curly">

  - `{{ nome }}`
  - `{{ etapa.atual }}`
  - `{{ project.data_inicio }}`
</Card>

  ```twig
    Olá! Obrigado por estar conosco.
  {% endif %}
  ```

<Card title="Loops (for)" icon="rotate">

## Variáveis dinâmicas

As variáveis permitem inserir dados dinamicamente no conteúdo.

### Sintaxe básica

```twig
{{ variavel }}
```

<Tabs>
<Tab title="Variáveis simples">
  ```twig
  Olá, {{ user.name }}!
  Seu e-mail é {{ user.email }}.
  ```
  
  **Resultado:**
  ```
  Olá, João Silva!
  Seu e-mail é joao@exemplo.com.
  ```
</Tab>

<Tab title="Variáveis aninhadas">
  ```twig
  Projeto: {{ project.code }} - {{ project.name }}
  Cliente: {{ project.customer.name }}
  Status: {{ project.status }}
  ```
  
  **Resultado:**
  ```
  Projeto: P-1 - Website Institucional
  Cliente: Acme Corp
  Status: 1
  ```
</Tab>

<Tab title="Arrays e listas">
  ```twig
  {% set lista = ['A', 'B', 'C'] %}
  Primeiro item: {{ lista[0] }}
  Último item: {{ lista[-1] }}
  Total de itens: {{ lista|length }}
  ```
  
  **Resultado (se lista = ['A', 'B', 'C']):**
  ```
  Primeiro item: A
  Último item: C
  Total de itens: 3
  ```
</Tab>
</Tabs>

### Verificação de existência

Antes de usar uma variável, você pode verificar se ela existe:

```twig
{% if variavel is defined %}
  A variável existe: {{ variavel }}
{% else %}
  A variável não está disponível
{% endif %}
```

<Tip>
Use `is defined` para evitar erros quando uma variável pode não estar disponível em todos os contextos.
</Tip>

## Condicionais

Condicionais permitem exibir conteúdo diferente baseado em condições.

### Estrutura if/else

<Tabs>
<Tab title="If simples">
  ```twig
  {% if usuario.idade >= 18 %}
    Você é maior de idade.
  {% endif %}
  ```
</Tab>

<Tab title="If/Else">
  ```twig
  {% if project.impact < 3 %}
    ⚠️ URGENTE: Este projeto requer atenção imediata!
  {% else %}
    📋 Projeto regular
  {% endif %}
  ```
</Tab>

<Tab title="If/Elseif/Else">
  ```twig
  {% if project.impact < 3 %}
    ✅ Projeto de alto impacto
  {% elseif project.impact < 5 and project.impact > 3 %}
    🚀 Projeto de médio impacto
  {% else %}
    ⚠️ Projeto de baixo
  {% endif %}
  ```
</Tab>

</Tabs>

### Operadores de comparação

<AccordionGroup>
<Accordion title="Igualdade e diferença" icon="equals">
  ```twig
  {% if valor == 10 %}      {# Igual a #}
  {% if valor != 10 %}      {# Diferente de #}
  ```
</Accordion>

<Accordion title="Comparações numéricas" icon="greater-than">
  ```twig
  {% if idade > 18 %}       {# Maior que #}
  {% if idade >= 18 %}      {# Maior ou igual #}
  {% if idade < 18 %}       {# Menor que #}
  {% if idade <= 18 %}      {# Menor ou igual #}
  ```
</Accordion>

<Accordion title="Operadores lógicos" icon="code-merge">
  ```twig
  {% if a and b %}          {# E lógico #}
  {% if a or b %}           {# OU lógico #}
  {% if not a %}            {# NÃO lógico #}
  ```
</Accordion>

<Accordion title="Testes especiais" icon="vial">
  ```twig
  {% if variavel is defined %}     {# Está definida #}
  {% if variavel is null %}        {# É nula #}
  {% if variavel is empty %}       {# É vazia #}
  {% if numero is even %}          {# É par #}
  {% if numero is odd %}           {# É ímpar #}
  ```
</Accordion>
</AccordionGroup>

## Loops (for)

Loops permitem iterar sobre listas e arrays para gerar conteúdo repetitivo.

### Estrutura básica

```twig
{% for item in lista %}
  {{ item }}
{% endfor %}
```

<Tabs>
<Tab title="Lista simples">
  ```twig
  Membros da equipe:
  {% for membro in equipe %}
  - {{ membro.nome }} ({{ membro.cargo }})
  {% endfor %}
  ```
  
  **Resultado:**
  ```
  Membros da equipe:
  - João Silva (Desenvolvedor)
  - Maria Santos (Designer)
  - Carlos Oliveira (Gerente)
  ```
</Tab>

<Tab title="Com índice">
  ```twig
  {% for item in lista %}
    {{ loop.index }}. {{ item }}
  {% endfor %}
  ```
  
  **Variáveis especiais do loop:**
  - `loop.index` - Índice atual (começa em 1)
  - `loop.index0` - Índice atual (começa em 0)
  - `loop.first` - True na primeira iteração
  - `loop.last` - True na última iteração
  - `loop.length` - Total de itens
</Tab>

<Tab title="Com condicionais">
  ```twig
  {% for tarefa in tarefas %}
    {% if tarefa.status == 'pendente' %}
      ⏳ {{ tarefa.nome }} - Pendente
    {% endif %}
  {% endfor %}
  ```
</Tab>

<Tab title="Loop vazio">
  ```twig
  {% for item in lista %}
    - {{ item }}
  {% else %}
    Nenhum item encontrado.
  {% endfor %}
  ```
  
  <Info>
  O bloco `else` é executado se a lista estiver vazia.
  </Info>
</Tab>
</Tabs>

### Loops com ranges

```twig
{% for i in 1..5 %}
  Número {{ i }}
{% endfor %}
```

**Resultado:**
```
Número 1
Número 2
Número 3
Número 4
Número 5
```

<Tip>
Use ranges para criar sequências numéricas facilmente.
</Tip>

## Filtros

Filtros transformam dados antes de exibi-los.

### Sintaxe de filtros

```twig
{{ variavel|filtro }}
{{ variavel|filtro(parametro) }}
{{ variavel|filtro1|filtro2 }}
```

<Tabs>
<Tab title="Texto">
  ```twig
  {{ nome|upper }}              {# JOÃO SILVA #}
  {{ nome|lower }}              {# joão silva #}
  {{ nome|capitalize }}         {# João silva #}
  {{ nome|title }}              {# João Silva #}
  {{ texto|trim }}              {# Remove espaços #}
  {{ texto|length }}            {# Conta caracteres #}
  {{ texto|json }}              {# Converte para JSON #}
  {{ texto|json(true) }}        {# Converte para JSON com identação #}
  ```
</Tab>

<Tab title="Números">
  ```twig
  {{ preco|number_format(2, ',', '.') }}
  {# 1.234,56 #}
  
  {{ valor|round }}             {# Arredonda #}
  {{ valor|round(2) }}          {# 2 decimais #}
  {{ valor|abs }}               {# Valor absoluto #}
  ```
</Tab>

<Tab title="Datas">
  ```twig
  {{ data|date("d/m/Y") }}      {# 21/01/2026 #}
  {{ data|date("d/m/Y H:i") }}  {# 21/01/2026 14:30 #}
  {{ data|date("F Y") }}        {# Janeiro 2026 #}
  ```
</Tab>

<Tab title="Arrays">
  ```twig
  {{ lista|length }}            {# Tamanho #}
  {{ lista|first }}             {# Primeiro item #}
  {{ lista|last }}              {# Último item #}
  {{ lista|join(', ') }}        {# Une com vírgula #}
  {{ lista|reverse }}           {# Inverte ordem #}
  {{ lista|sort }}              {# Ordena #}
  {{ lista|unique }}            {# Remove duplicatas #}
  {{ lista|json }}              {# Converte para JSON #}
  {{ lista|json(true) }}        {# Converte para JSON com identação #}
  ```
</Tab>

<Tab title="Objetos">
  ```twig
  {{ objeto|json }}              {# Converte para JSON #}
  {{ objeto|json(true) }}        {# Converte para JSON com identação #}
  ```
</Tab>
</Tabs>

### Filtros especiais da Olie

<AccordionGroup>
<Accordion title="mention" icon="at">
  Cria uma menção de usuário automaticamente.
  
  ```twig
  {{ usuario|mention }}
  ```
  
  [Saiba mais sobre menções →](/guides/automation/mention-users)
</Accordion>

<Accordion title="default" icon="shield-halved">
  Define um valor padrão se a variável for vazia.
  
  ```twig
  {{ nome|default('Nome não informado') }}
  ```
</Accordion>

<Accordion title="escape" icon="shield">
  Escapa caracteres especiais para segurança.
  
  ```twig
  {{ texto|escape }}
  {{ texto|e }}  {# Atalho #}
  ```
</Accordion>

<Accordion title="json" icon="code">
  Converte para JSON. Muito útil para debugar e exibir dados em formato JSON.
  
  ```twig
  {{ lista|json }}              {# Converte para JSON #}
  {{ lista|json(true) }}        {# Converte para JSON com identação #}
  ```
</Accordion>
</AccordionGroup>
 
## Funções de consulta

Nem tudo que você precisa está disponível no contexto. A função `query` busca o que falta, direto da plataforma, no meio da expressão.

### Sintaxe

```twig
query('nome_da_consulta', { 'parametro': valor })
```

O retorno é uma estrutura de dados, não um texto — por isso `query` quase sempre vem com `set`:

```twig
{% set p = query('project_details', { 'project_code': project.code }) %}
{{ p.name }}
```

### Consultas disponíveis

| Consulta | Parâmetros | Devolve |
| --- | --- | --- |
| `project_details` | `project_code` **ou** `id` | O projeto completo, com etiquetas, funis, etapas e respostas |
| `project_dynamic_forms` | `project_code` | Os formulários dinâmicos do projeto; cada item traz `pivot` e `form_answers` |
| `project_medias` | `project_code` | `medias` (o conteúdo publicado no projeto) e `pagination` |
| `get_form_answers` | [`pivot`](/api-reference/general/form-answer-pivot) — opcionais: `edge_id`, `format` | As respostas de um formulário, dentro de `response` |
| `user_details` | `user_id` | Os dados de um usuário |
| `user_email` | `user_id` | O e-mail principal do usuário, como texto |

### Exemplos

<Tabs>
<Tab title="Etiquetas do projeto">
  Etiquetas não vêm carregadas no contexto — é preciso buscá-las:

  ```twig
  {% set p = query('project_details', { 'project_code': project.code }) %}
  {% for tag in p.tags %}{{ tag.name }}{% if not loop.last %}, {% endif %}{% endfor %}
  ```
</Tab>

<Tab title="Respostas de um formulário">
  `get_form_answers` precisa do `pivot` — o endereço que diz **onde** o formulário está anexado. Ele vem pronto de `project_dynamic_forms`, e as duas consultas se encadeiam:

  ```twig
  {% set formularios = query('project_dynamic_forms', { 'project_code': project.code }) %}
  {% for f in formularios %}
    {% set respostas = query('get_form_answers', { 'pivot': f.pivot }) %}
    {{ respostas.response|json(true) }}
  {% endfor %}
  ```
</Tab>

<Tab title="E-mail de um responsável">
  ```twig
  {% for u in project.users %}{{ query('user_email', { 'user_id': u.id }) }}
  {% endfor %}
  ```
</Tab>

<Tab title="Descobrir o formato">
  Na dúvida sobre o que a consulta devolve, imprima tudo uma vez e olhe o resultado no registro de execução:

  ```twig
  {{ query('project_medias', { 'project_code': project.code })|json(true) }}
  ```
</Tab>
</Tabs>

### Cuidados

<AccordionGroup>
<Accordion title="Limite de consultas" icon="gauge-high">
  Cada expressão pode executar no máximo **50 consultas**. Um `query` dentro de um laço conta uma vez por iteração — cuidado ao consultar dentro de `for`.
</Accordion>

<Accordion title="Quando a consulta não encontra nada" icon="circle-question">
  O retorno é nulo. Proteja antes de usar:

  ```twig
  {% set p = query('project_details', { 'project_code': project.code }) %}
  {% if p %}{{ p.name }}{% else %}Projeto não encontrado{% endif %}
  ```
</Accordion>

<Accordion title="Nome ou parâmetro errado" icon="triangle-exclamation">
  Um nome de consulta que não existe, ou a falta de um parâmetro obrigatório, interrompe a expressão e registra `template_error`. O [registro de execução](/guides/automation/logs) mostra a mensagem.
</Accordion>

<Accordion title="Escopo e repetição" icon="shield-halved">
  As consultas são resolvidas sempre dentro da sua própria conta — não há como acessar dados de outra. E a mesma consulta, com os mesmos parâmetros, é reaproveitada em vez de repetida.
</Accordion>
</AccordionGroup>

## Como funciona o mecanismo

Por trás da sintaxe avançada, a plataforma utiliza um mecanismo baseado no **Twig**, uma das engines de templates mais modernas e seguras do ecossistema web.

<Info>
O Twig é amplamente adotado por frameworks robustos e foi adaptado aqui para permitir **automação lógica dentro dos conteúdos da plataforma**, de forma controlada e intuitiva.
</Info>
