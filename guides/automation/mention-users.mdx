Uma automação pode mencionar usuários nas mensagens que escreve, como na ação [Envia conteúdo do projeto](/guides/automation/actions-integrations#envia-conteúdo-do-projeto). A menção é gerada a partir das [variáveis](/guides/automation/variables) da automação, de dois jeitos: com o filtro `mention`, que é o caminho mais simples, ou montando o formato da menção à mão.

## Usar o filtro mention

O filtro `mention` gera a menção no formato correto, sem que você precise montá-lo. Ele funciona com um objeto que contenha o ID de um usuário ou com uma lista de usuários que tenham o ID.

```twig
Olá {{ user|mention }}, você tem uma nova tarefa.
```

Para mencionar os usuários do projeto, aplique o filtro na lista:

```twig
{{ project.users|mention }}
```

A variável `user` só existe quando uma pessoa disparou a automação. Em disparos por agendamento, como projeto ocioso ou data atingida, ela não existe. Por isso, confira se a variável existe antes de aplicar o filtro, para evitar erro na mensagem:

```twig
{% if user is defined %}Olá {{ user|mention }}, você tem uma nova tarefa.{% endif %}
```

Veja o que cada disparo traz em [Quem disparou](/guides/automation/variables#quem-disparou).

## Montar a menção manualmente

O sistema reconhece menções neste formato:

```text
<u@00000000-0000-0000-0000-000000000000:Nome>
```

O formato tem quatro partes:

- **`<u@`**: prefixo que indica uma menção de usuário;
- **ID do usuário**: identificador único do usuário, representado acima por zeros;
- **`:`**: separador entre o ID e o nome;
- **Nome do usuário**: texto exibido na menção.

Com a [sintaxe avançada](/guides/advanced/advanced-syntax), você preenche o ID e o nome com variáveis:

```twig
Olá <u@{{ user.id }}:{{ user.name }}>, você foi designado para esta tarefa.
```

O filtro `mention` gera esse mesmo formato e evita erros de digitação na montagem. Prefira o filtro sempre que tiver o objeto do usuário.
