No ChatGPT e no Claude, a Olie tem uma página própria no catálogo de cada assistente. Você abre essa página, conecta, entra na Olie e escolhe o workspace, que é a [empresa](/guides/fundamentals/glossary#pessoas-e-conta) na Olie. Nos editores de código e em outros clientes, você informa o endereço do servidor.

```text Endereço do servidor MCP
https://api.olie.ai/mcp/management
```

## Antes de começar

Faça a primeira conexão **no computador**. Os aplicativos de celular exibem as conexões já autorizadas, mas não oferecem a tela de conexão.

## ChatGPT

A Olie está publicada como plugin **Olie Flow AI** no catálogo do ChatGPT.

<Steps>
<Step title="Abra a página do plugin" icon="arrow-up-right-from-square">
  No computador, abra a [página do Olie Flow AI no ChatGPT](https://chatgpt.com/plugins/plugin_asdk_app_6a31dd76881c8191964e8f46ba95c8c6) com a sua conta.
</Step>

<Step title="Conecte o plugin" icon="plug">
  Clique no botão de conectar. O ChatGPT abre a tela de consentimento da Olie.
</Step>

<Step title="Entre e escolha o workspace" icon="building">
  Entre com o seu usuário da Olie, selecione o workspace que essa conexão vai enxergar e autorize o acesso.

  <Check>
  Numa conversa nova, pergunte "Quais são os meus funis na Olie?" e o ChatGPT responde com os funis do workspace escolhido.
  </Check>
</Step>
</Steps>

## Claude

A Olie está publicada como conector **Olie Flow AI** no diretório do Claude.

<Steps>
<Step title="Abra a página do conector" icon="arrow-up-right-from-square">
  No computador, abra a [página do Olie Flow AI no Claude](https://claude.ai/directory/olie-flow-ai) com a sua conta.
</Step>

<Step title="Conecte o conector" icon="plug">
  Clique no botão de conectar. O Claude abre a tela de consentimento da Olie.
</Step>

<Step title="Entre e escolha o workspace" icon="building">
  Entre com o seu usuário da Olie, selecione o workspace que essa conexão vai enxergar e autorize o acesso.
</Step>

<Step title="Ative na conversa" icon="comment">
  No seletor de ferramentas da conversa, ative a Olie.

  <Check>
  Pergunte "Quais são os meus funis na Olie?" e o Claude responde com os funis do workspace escolhido.
  </Check>
</Step>
</Steps>

## No celular

A conexão criada no computador está ligada à sua conta do assistente, então aparece sozinha no celular.

<Steps>
<Step title="Abra o aplicativo" icon="mobile">
  Entre no ChatGPT ou no Claude com a mesma conta que você usou no computador.
</Step>

<Step title="Localize a Olie nas ferramentas" icon="grid-2">
  Na conversa, abra a área de ferramentas. A Olie aparece na lista, já autorizada.
</Step>

<Step title="Pergunte normalmente" icon="comment">
  As mesmas perguntas do computador funcionam aqui.

  <Check>
  O assistente responde com os dados do mesmo workspace escolhido no computador.
  </Check>
</Step>
</Steps>

## Claude Code

Um comando resolve:

```bash Terminal
claude mcp add --transport http olie-flow-ai https://api.olie.ai/mcp/management
```

Na primeira chamada de ferramenta, o Claude Code abre o navegador para a autorização. Depois disso, verifique o estado da conexão com:

```bash Terminal
claude mcp list
```

## Cursor e outros clientes

Qualquer cliente compatível com MCP remoto aceita o endereço do servidor como conector personalizado. Nos clientes que leem um arquivo de configuração, use o formato padrão:

```json mcp.json
{
  "mcpServers": {
    "olie-flow-ai": {
      "type": "http",
      "url": "https://api.olie.ai/mcp/management"
    }
  }
}
```

<Tip>
Não coloque token nem chave nesse arquivo. A autenticação é feita por OAuth no primeiro uso, e as credenciais ficam guardadas pelo próprio cliente — nunca no arquivo de configuração.
</Tip>

## Como funciona a autorização

A conexão usa **OAuth**, o mesmo mecanismo de "entrar com a sua conta" usado em outros sites e aplicativos. Nenhum token precisa ser copiado ou guardado: a partir da URL, o assistente descobre para onde mandar você autenticar e depois cuida da renovação.

Sua senha nunca passa pelo assistente, porque o login acontece na própria Olie.

## Problemas comuns

<AccordionGroup>
<Accordion title="O assistente diz que não tem acesso à Olie" icon="plug-circle-xmark">
  Confirme que a conexão está ativada **naquela conversa**. Em vários clientes, adicionar o conector não o liga automaticamente em todos os chats — é preciso selecioná-lo no seletor de ferramentas.
</Accordion>

<Accordion title="Os dados são de outro workspace" icon="building">
  O workspace é definido no momento da autorização e não muda sozinho. Remova a conexão e crie de novo, escolhendo o workspace correto na tela de consentimento. Para acompanhar outro workspace ao mesmo tempo, adicione o endereço do servidor como conector personalizado, com um nome diferente, e escolha o outro workspace na autorização.
</Accordion>

<Accordion title="Parou de funcionar depois de um tempo" icon="clock">
  A autorização expirou e a renovação falhou. Reconecte pelo assistente para refazer o login.
</Accordion>

<Accordion title="Faltam projetos no resultado" icon="eye-slash">
  O MCP só enxerga o que o seu usuário enxerga na plataforma. Se um projeto não aparece, verifique as suas permissões em [Papéis e permissões](/guides/users/roles-permissions).
</Accordion>

<Accordion title="A resposta veio truncada" icon="scissors">
  Algumas consultas retornam volume alto — a lista completa de funis de uma conta grande, por exemplo. Refine a pergunta citando o funil, a etapa ou o período em vez de pedir tudo de uma vez.
</Accordion>
</AccordionGroup>
